ADMIN · Досье по доменам

Краткие шпаргалки: стиль, кюве, отличия, визиты, что брать.

Château Puech-Haut (Saint-Drézéry) — икона региона, мощный южный стиль, высокая стабильность.
Стиль
Плотные красные на Syrah/Grenache с выразным фруктом и специями; белые — ароматные, с объёмом; розе — эталонный «южник».
Ключевые кюве
  • Tête de Bélier (R/B) — флагман, коллекционный потенциал.
  • Prestige (R/W) — «золотая середина» по цене/качеству.
  • Argali Rosé — популярное сухое розе.
Достижения
Регулярные 90+ баллов у критиков, высокая узнаваемость бренда, коллаборации с художниками (баррели/этикетки).
Визит
По записи, 60–75 мин, англ/фр; дегустация часто ~€10–15/чел (иногда вычитают при покупке). Парковка удобная.
Фокус покупок
Prestige R/W для гостей; Tête de Bélier — коллекционерам; Rosé Argali — «быстрый восторг».
Château La Roque (Fontanès) — biodynamie, историческое поместье, авторитетные красные PSL.
Стиль
Красные с тонкой свежестью и структурой; акцент на Syrah/Grenache, с минеральным фоном. Белые — редкость, часто с фенольной структурой.
Ключевые кюве
  • Clos La Roque — мощный PSL с потенциалом выдержки.
  • Blanc (в лимите) — минеральный, гастрономичный.
Достижения
Сертификация Demeter (биодинамика), стабильные 90+ баллов в Decanter/WA, известен в проф-среде.
Визит
По записи; дегустации на французском/английском; при больших группах возможен аперитив в саду.
Фокус покупок
Красные PSL среднего и высокого уровня — выгодно брать кейсами; белый — как редкость «для коллекции».
Château de Cazeneuve (Lauret) — элегантность PSL, известняк/доломит, тонкие таннины.
Стиль
Больше свежести и пикантности, чем силы; акцент на пряность, графит, травы гаррига.
Ключевые кюве
  • Серия PSL красных (Syrah-driven) — гастрономичность.
  • Белые — ограниченные тиражи, минеральность.
Достижения
Исторический замок, стабильные отзывы винных гидов; выдержанный стиль ценят сомелье.
Визит
По записи; возможны прогулки по терруару при хорошей погоде.
Фокус покупок
Красные PSL «середины» — оптимальны по цене/элегантности.
Clos Marie (Lauret) — терруарная глубина, био/минимализм, sought-after кюве.
Стиль
Слоистые, медитативные, с потенциалом; меньше «глянца», больше терруара.
Ключевые кюве
  • Красные PSL (Syrah/Grenache) — выдержка приветствуется.
  • Белые — редкость, минеральные, с объёмом.
Достижения
Культовый статус среди ценителей PSL; лимитированные квоты.
Визит
Строго по записи; небольшие группы.
Фокус покупок
Брать «на полку»/в подвал; предупреждать о стиле гостя (не «сладко-фруктовый»).
Mas Bruguière (Valflaunès) — референс PSL: точность, чистота, баланс.
Стиль
Чёткие, гармоничные вина: спелость без тяжести, графит/лавровый лист, свежая кислотность.
Ключевые кюве
  • L’Arbouse — доступный вход в стиль хозяйства.
  • La Grenadière — шаг выше по сложности.
Достижения
Частые рекомендации гидами региона; стабильность по годам.
Визит
По записи, гибкие окна; дружелюбная команда.
Фокус покупок
L’Arbouse кейсами для «домашнего PSL»; La Grenadière на подарки.
Domaine de l’Hortus (Valflaunès) — пионеры долины, сильная линейка Bergerie/Grande Cuvée.
Стиль
Солнечные, но собранные; красные с плотным ядром, белые зрелые, гастрономичные.
Ключевые кюве
  • Bergerie de l’Hortus (R/W) — «умная база».
  • Grande Cuvée (R/W) — флагман, потенциал.
Достижения
Один из брендов-амбассадоров PSL; высокие оценки базовых серий.
Визит
Часто возможно «добавить» в маршрут по ситуации днём.
Фокус покупок
Bergerie кейсами; Grande Cuvée — в коллекцию/подарки.
Общее по маршруту — тайминг, расстояния, напоминания.
Тайминг
Между доменами 10–25 мин. Не затягивать первую дегустацию; обед бронировать заранее.
Биллинги
Дегустации чаще оплачиваются на месте; иногда возвращаются при покупке.
Безопасность
Водитель не дегустирует; воду держать в машине.
Погода
В жару — теневые стоянки; на панораме PSL — шляпы/крем.
